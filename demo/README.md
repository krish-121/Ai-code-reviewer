# Public Sentinel sample

Follow [the runnable public demo guide](../docs/PUBLIC_DEMO.md) for installation, browser steps and explanations. The AI replies are scripted; analysis, verification, Docker validation and explicit Apply are real.

The [sample templates](sentinel-demo-repo/) contain a base shop and an intentionally buggy feature. [build_demo_repo.py](build_demo_repo.py) creates their two-branch Git repository locally. All credentials are invented scanner fixtures. No real keys or accounts are needed.
