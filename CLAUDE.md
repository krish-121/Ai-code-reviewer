# Notes for AI assistants working on this repository

- Follow [`CONTRIBUTING.md`](CONTRIBUTING.md): the code-quality standard and the checks to
  run before every commit.
- The spec is [`docs/SPEC.md`](docs/SPEC.md). Re-read the relevant sections before
  changing a feature.
- [`PROGRESS.md`](PROGRESS.md) has the build status, assumptions, what is verified only
  with mocks, and the open *NEEDS REVIEW* decisions. Keep it up to date.
- The owner is learning from this code: prefer the simplest readable design, and explain
  non-obvious choices in docstrings.
